# # Региональный Склад («Электроника Волгодонска»)

Веб-платформа и PWA-приложение для обмена, дарения и продажи электронных компонентов из рук в руки, а также поиска мастеров по ремонту электроники с встроенным чатом в реальном времени.

**Продакшен:** [https://elplus7.ru](https://elplus7.ru)

---

## Основные возможности

* **Каталог электронных компонентов:** загрузка запасов через таблицы (XLSX/CSV), поиск по наименованию и городу, управление позициями.
* **База мастеров по ремонту:** анкеты специалистов с указанием специализации, резюме и контактов.
* **Чат в реальном времени:** общий чат и личные сообщения на базе Socket.IO с поддержкой отправки изображений (автоматическая конвертация в WebP) и статусами онлайн.
* **Панель администратора:** модерация жалоб, фильтр запрещённых слов, управление пользователями и очистка устаревших медиафайлов.
* **PWA (Progressive Web App):** поддержка установки на мобильные устройства и работы через Service Worker.

---

## Стек технологий

* **Backend:** Node.js, Express
* **Real-time:** Socket.IO 4.7
* **База данных:** PostgreSQL 16
* **Обработка файлов и медиа:** Multer, Sharp (сжатие в WebP), SheetJS (`xlsx`)
* **Почтовые уведомления:** Nodemailer (SMTP)
* **Frontend:** Vanilla HTML5, CSS3, ES6+ JavaScript, PWA (`manifest.json`, `sw.js`)
* **Инфраструктура:** Nginx (reverse proxy + статика), PM2

## Схема базы данных (PostgreSQL)

Проект использует 9 основных таблиц в схеме `public`:

* `users` — учётные записи пользователей, роли, контакты, статусы блокировки и права администратора.
* `components` — каталог электронных компонентов пользователей (название, категория, количество, цена, состояние, город).
* `chat_messages` — сообщения общего чата.
* `private_messages` — личные сообщения между пользователями со статусом прочтения.
* `chat_reports` — жалобы пользователей на сообщения и участников чата.
* `banned_words` — словарь запрещённых слов для автомодерации.
* `chat_info_messages` — системные информационные сообщения в чатах.
* `chat_settings` — глобальные настройки работы чата.
* `admin_chat_access` — журнал аудита доступа администраторов к перепискам.

## API и WebSocket

* **REST API:** все маршруты сгруппированы под префиксом `/api/volgodonsk/` (авторизация, управление компонентами, профиль, история чатов, администрирование).
* **Socket.IO:** события в реальном времени для доставки сообщений (`new_message`), удаления (`message_deleted`, `message_admin_deleted`), отслеживания онлайна (`users_online`) и статусов прочтения (`messages_read`).

## Запуск и развёртывание

1. **Установите зависимости:**
   ```bash
   npm install
   ```

2. **Настройте конфигурацию:**
   Заполните параметры подключения к PostgreSQL, секретный ключ JWT и настройки SMTP в директории `src/config/` (или через переменные окружения).

3. **Запустите сервер через PM2:**
   ```bash
   pm2 start ecosystem.config.js
   ```

4. **Обслуживание:**
   * Перезапуск приложения: `pm2 restart ecosystem.config.js`
   * Очистка устаревших файлов: `node cleanup.js`
